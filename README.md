# BloomGuard 🌿🤖

> **Smart AI-Powered Plant Care, Disease Diagnostics & Garden Companion**

BloomGuard is a modern web application built with **Next.js 16**, **React 19**, and **TypeScript**. It empowers plant enthusiasts, gardeners, and botanists to care for their plants using AI-driven disease detection, personalized care planners, a comprehensive plant database, and an active gardening community.

## ✨ Features

### 🤖 AI Assistant & Disease Diagnostics
- **Photo & Text Analysis:** Upload plant photos or describe symptoms to diagnose diseases, pest infestations, or nutrient deficiencies instantly.
- **Smart Care Advice:** Receive actionable recovery steps, watering adjustments, and light recommendations generated by AI.

### 🪴 My Garden Management
- **Personal Plant Collection:** Add and organize your indoor and outdoor plants with custom photos, acquisition dates, and custom notes.
- **Health Tracking:** Monitor growth logs, status indicators (Healthy, Needs Attention, Recovering), and treatment history.

### 📅 Smart Care Planner
- **Custom Care Schedules:** Dynamic watering, fertilizing, repotting, and pruning reminders tailored to plant species and season.
- **Visual Analytics:** Interactive dashboards using [Recharts](https://recharts.org/) to track care consistency and plant health metrics over time.

### 🔍 Plant Library & Exploration
- **Extensive Database:** Search, filter, and discover plant species by care difficulty, light requirements, pet safety, and categories (Foliage, Succulents, Flowering, Herbs).
- **In-depth Care Guides:** Detailed instructions covering optimal temperature, humidity, soil type, and propagation tips.

### 💬 Community Hub
- **Gardening Forum:** Ask questions, share plant growth milestones, swap cuttings, and exchange expert tips with fellow plant lovers.
- **Interactive Discussions:** Filter by topic, like posts, and contribute to community threads.

### 🔐 Authentication & User Profiles
- Secure registration, user login, token-based authentication session management, and customized user profiles.

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed on your local machine:
- **Node.js:** `v18.17.0` or higher
- **Package Manager:** `npm` (v9+), `yarn`, `pnpm`, or `bun`

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/kibriya41/BloomGuard.git
   cd BloomGuard/bloomguard
   ```

2. **Install dependencies:**
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```

### Environment Variables

Create a `.env.local` file in the root directory and add the backend API endpoint configuration:

```env
NEXT_PUBLIC_API_URL=http://localhost:5000/api
```

### Running Development Server

Start the Next.js development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### Building for Production

To generate an optimized production build:

```bash
npm run build
```

To start the production server:

```bash
npm run start
```

## 🔌 API & Backend Integration

BloomGuard frontend interacts with a REST API backend. The API base URL is controlled via the `NEXT_PUBLIC_API_URL` environment variable in [src/lib/api.ts](file:///d:/ts%20project/BloomGuard/bloomguard/src/lib/api.ts).

Authentication tokens are automatically stored in `localStorage` (`bloomguard_token`) and attached as a `Bearer` token header on outgoing requests via an Axios interceptor.
